# 프로젝트 규칙

## 절대 규칙

- 사용자의 허락 없이 파일을 바로 수정하지 않는다.
- 큰 작업은 반드시 먼저 계획을 제시한다.
- 초심자도 이해할 수 있게 설명한다.
- 코드 변경 전에는 어떤 파일을 수정할지 먼저 말한다.
- 실행한 명령어와 결과를 간단히 요약한다.

## 설명 방식

- 먼저 결론을 말한다.
- 그다음 왜 필요한지 설명한다.
- 마지막에 실제 코드 흐름을 설명한다.

## NestJS 학습 규칙

- Controller는 요청을 받는 입구로 설명한다.
- Service는 실제 비즈니스 로직을 처리하는 곳으로 설명한다.
- Module은 관련 기능을 묶는 상자로 설명한다.
- DTO는 요청 데이터의 모양을 정하는 도구로 설명한다.

## 명령어

- 개발 서버 실행: npm run start:dev
- 빌드: npm run build
- 테스트: npm run test
